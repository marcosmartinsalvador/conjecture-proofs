# Restricting a positively expansive map keeps it positively expansive

## In plain words

If an endomorphism of a torsion abelian group is positively expansive, then so is its restriction to any subgroup it maps into itself.

The paper prints "expansive endomorphism", a term it does not define; it defines "expansive" only for automorphisms and "positively expansive" for endomorphisms. The statement proved here reads the hypothesis as "positively expansive". Under another reading this would be a different statement. The proof is short (Hilbert's basis theorem), so a specialist might call it easy.

## The statement as printed

M. Achigar, "Algebraic expansivity on abelian groups", arXiv:2604.24556v1 (27 April 2026), the conjecture closing the paper.

> **Conjecture.** Let $\varphi \colon G \to G$ be an expansive endomorphism of a torsion
> group $G$. If $H \leq G$ is a subgroup such that $\varphi H\subseteq H$, then the
> restriction $\varphi|_H \colon H \to H$ is also positively expansive.

## What is proved here

`Claim`: for a torsion abelian group G and an endomorphism φ of G that is positively expansive, the restriction of φ to any subgroup H with φ(H) ⊆ H is positively expansive.

**How the Lean statement reads the source.**

- **The one judgement call.** The conjecture says "an expansive endomorphism", but the
  paper defines "expansive" only for automorphisms and "positively expansive" for
  endomorphisms. `Statement.lean` reads the hypothesis as "φ is a positively expansive
  endomorphism". Reasons: (1) the conclusion says "is *also* positively expansive";
  (2) the conjecture is the endomorphism twin of the theorem before it, with `φH = H`
  relaxed to `φH ⊆ H`; (3) the other reading (φ an expansive automorphism, conclusion
  positive expansivity) is false, and the author knows it: the two-sided Bernoulli
  shift on `⊕_ℤ S` is an expansive automorphism that is not positively expansive
  (take `H = G`).
- `∑_{k=0}^n φ^k S` is the sum of the subgroups `S, φS, ..., φ^n S`. `Statement.lean`
  writes it elementwise (`sumIterates`): all `∑_{k=0}^n φ^k(s_k)` with `s_k ∈ S`.
- "Torsion group": every element has finite order, written
  `∀ g, ∃ n, 0 < n ∧ n • g = 0`.
- `φ|_H` is `(φ.comp H.subtype).codRestrict H _`, the map `x ↦ φ x` on `H`.
- Groups are abelian (`AddCommGroup`), in `Type` (universe 0), which is the usual way
  to state such a result without universe parameters.
- The definition is not vacuous either way: the zero map on `⊕_ℕ ℤ/2` is not
  positively expansive, the one-sided shift on it is.

## Idea of the proof

Make `G` a module over the polynomial ring `ℤ[X]`, with `X` acting as `φ`. For a
torsion group, "`φ` is positively expansive with generator `S`" says exactly
`G = ∑_k φ^k S`, that is, the finite set `S` generates `G` as a `ℤ[X]`-module. An
invariant subgroup `H` is a submodule. `ℤ[X]` is Noetherian (Hilbert's basis theorem),
so `H` is generated by finitely many elements. The subgroup `S₀` they generate is
finite, because a finitely generated torsion abelian group is finite, and
`H = ∑_k φ^k S₀`. So `S₀` is a positive generator for `φ|_H`.

The same argument with `ℤ[X, X⁻¹]` gives the paper's theorem for automorphisms without
duality, which is the "purely algebraic approach" the paper asks for. That part is
not formalised here.
